# Hide Implicit

Hides the **Implicit** tab on your Friends page.

> [!NOTE]
> The tab comes from Vencord's own **ImplicitRelationships** plugin. This only hides it: that
> plugin keeps working, and the tab is back the moment this is switched off.

## Using it

Switch the plugin on. The Implicit tab is gone from the Friends header. If you were on that tab
at the time, the page moves to **All**.

It can be switched from **Additional Settings** like the others, and Screen Share Protection
turns it on while you share your screen.

## Is this safe?

Yes. It changes what your own client draws and nothing else.
