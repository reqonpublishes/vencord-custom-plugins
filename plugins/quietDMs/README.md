# Quiet DMs

**Message** opens the DM in your sidebar without taking you to it, so you can go down your
friends list opening DMs without going back and scrolling each time.

- The chat button on a friend's row on the Friends page
- **Message** in the right-click menu on a person

Clicking a friend's row itself still goes to the DM as usual. A short note says each one opened.

Meant to be switched on for a while and off again. Switching it on or off needs a reload, since
the chat button is changed inside Discord's own Friends list.
