# Fake Calls

Add a call to any DM: who rang, when, how long it lasted, and whether you picked up.

> [!NOTE]
> Nothing is sent to Discord and nobody is rung. The call exists in your client and nowhere
> else.

## Using it

**In a DM** — right-click any message → **Add Call Here**, or right-click the conversation
or the person → **Add Call**.

Then choose:

| | |
| --- | --- |
| **Started by** | Them or you — whether it reads as a call you made or one you were given |
| **Started** | The date and time. Like any message, that is also where it sits in the conversation |
| **Lasted** | In minutes, with chips for the usual lengths |
| **Missed call** | You were not on it, so it reads as one you missed |
| **Still going** | No end, so the timer counts up and the call looks live |

**Taking one back** — right-click the call → **Remove Added Call**. To clear a whole
conversation, right-click it → **Remove ... Added Calls**.

> [!TIP]
> There is no "duration" to set and none is stored. Discord works the length out from when
> the call started and ended, which is why the line under it says "lasted 5 minutes" in your
> language without this plugin writing a word of it.

## Settings

| Setting | What it does |
| --- | --- |
| **Add "Add Call Here" to the right-click menu on a message in a DM** | The entry on a message |
| **Add "Add Call" when you right-click a DM or a person** | The entry in the sidebar and on people |
| **Remember added calls after Discord restarts** | Off means they last until you close Discord |
| **Take every added call away** | Removes all of them, everywhere |

## Is this safe?

Yes. A call in your history is a message of a particular kind, and this builds one the way
Discord builds the ones it receives. Nothing is sent and nobody else sees it.

## Syncing

Install **[Sync](../cloudSync)** and the calls you add can follow you to your phone, and
back.
