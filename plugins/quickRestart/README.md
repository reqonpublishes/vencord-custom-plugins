# Quick Restart

Ctrl+R restarts Discord the way it always did, without the window going blank.

| You press | What happens |
| --- | --- |
| `Ctrl+R` | Discord restarts for real: new updates, every plugin, everything. A still picture of the window stays up until the new one is drawn, so you never see it go blank |
| `Ctrl+R` in a call | A warning first, because restarting leaves the call. Press again within a few seconds to go ahead |
| `Ctrl+Shift+R` | Discord's own reload, untouched |

> [!NOTE]
> The picture needs a helper that starts with Discord. After installing or updating this
> plugin, quit Discord fully once (tray icon → Quit) and open it again. Until then Ctrl+R still
> restarts, just with the usual blank flash.

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| Restart shortcut | `ctrl+r` | Modifiers and a key joined by `+` |
| Restart now | | **Restart and Resync**, **Plugins Only** (a few milliseconds, no reload), **Reload** and **Restart Discord**, with the times of the last restart |
