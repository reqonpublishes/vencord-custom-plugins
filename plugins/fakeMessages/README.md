# Fake Messages

Put a message in a conversation that nobody sent.

> [!NOTE]
> Nothing is sent to Discord. The message exists in your client and nowhere else — the
> other person sees an ordinary conversation, and no server ever hears about it.

## Using it

**In a chat** — right-click any message → **Add Message Here**. The box opens already
filled in with that person, a minute after what they said, because a message you invent is
usually an answer to something.

**From the sidebar** — right-click a DM or channel → **Add Message**. Same box, starting
from you and from now.

Then choose:

| | |
| --- | --- |
| **From** | Whose message it is. **Me** and **Them** fill it in for you, or paste any user ID |
| **Sent** | The date and time it should sit at. The chips nudge it by a day, an hour or five minutes |
| **Highlighted message** | Draws it as though it had mentioned you |
| **Show "(edited)" tag** | Adds the edited marker |
| **Says** | What the message says |

**Taking one back** — right-click it → **Remove Added Message**. To clear a whole
conversation, right-click it in the sidebar → **Remove ... Added Messages**.

> [!TIP]
> The time you pick is the position it takes. Discord orders a channel by when a message
> was sent, so set it to last Tuesday and it sits in last Tuesday, between the real ones —
> not at the bottom.

## Settings

| Setting | What it does |
| --- | --- |
| **Add "Add Message Here" to the right-click menu on a message** | The entry on a message |
| **Add "Add Message" when you right-click a DM or channel** | The entry in the sidebar |
| **Remember added messages after Discord restarts** | Off means they last until you close Discord |
| **Take every added message away** | Removes all of them, everywhere |

## Is this safe?

Yes, in the sense that matters: nothing here talks to Discord. The message is built the
same way Discord builds the ones it receives, handed to your own client, and stored on
your computer. Nothing is sent, nothing is edited server-side, and nobody else can see it.

> [!IMPORTANT]
> It is a message in *your* Discord. Screenshots of it are not evidence of anything, and
> treating them as if they were is the one way to use this badly.

## Syncing

Install **[Sync](../cloudSync)** and the messages you add here can follow you to your
phone, and back.
