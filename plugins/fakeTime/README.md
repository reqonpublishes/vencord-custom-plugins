# Fake Time

Move a conversation, or part of one, to another time - in your own Discord only. Off until you
switch it on.

> [!NOTE]
> Nothing is sent to Discord and nobody is told. Every message you move moves by the same
> amount, so the order, the gaps between messages and the day breaks all stay true.

## Using it

**A whole conversation:** right-click a DM, a channel or a person → **Fake Options** →
**Fake Time**. Set when the latest message was sent - with the calendar, or the buttons under
it - and press **Apply**. Every other message moves with it.

**Part of one:** right-click the first message → **Fake Options** → **Fake Time From Here...**,
then the last → **Fake Time Up To Here**. Set when the first of them was sent. Only those
messages move. If the new time would put them after the message that follows (or before the
one in front), the window says so, since Discord keeps messages in the order they were sent.

A part can sit inside a conversation you moved as a whole - the part's own time wins. Right-click
any message in a moved part → **Change Fake Time** to change it again.

Fake messages and fake calls move too, so you set the time once instead of on every fake
message.

## Settings

| Setting | What it does |
| --- | --- |
| **Show in menus** | Which right-click menus show Fake Time: messages, conversations, people |
| **Keep after restart** | Off means every chat is back to its real time next time you open Discord |
| **Moved** | Every conversation and part you moved: click one to change it, or reset it |
