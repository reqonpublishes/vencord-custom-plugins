# Fake Time

Move a conversation to another time - in your own Discord only. Off until you switch it on.

> [!NOTE]
> Nothing is sent to Discord and nobody is told. Every message in the chat moves by the same
> amount, so the order, the gaps between messages and the day breaks all stay true.

## Using it

Right-click a DM, a channel or a person → **Fake Options** → **Fake Time**. Set when the
latest message was sent - with the calendar, or the buttons under it - and press **Apply**.
Every other message moves with it.

Fake messages and fake calls in that chat move too, so you set the time once instead of on
every fake message.

## Settings

| Setting | What it does |
| --- | --- |
| **Show in menus** | Which right-click menus show Fake Time |
| **Keep after restart** | Off means every chat is back to its real time next time you open Discord |
| **Moved conversations** | Every chat you moved: click one to change it, or reset it |
